Guia de Configuració a GitHub Pages

Pas a pas per utilitzar MMA_2025.jpg i publicar la web en obert.

1

Desar la imatge local MMA_2025.jpg

Desa la imatge adjunta al projecte amb el nom exacte MMA_2025.jpg al mateix directori arrel que index.html.

2

Estructura del repositori

┌── index.html (Fitxer principal HTML) ├── MMA_2025.jpg (Foto de perfil de la Dra. Mitjans) └── README.md (Descripció opcional)
3

Activar GitHub Pages

  • Crea un repositori públic a GitHub i puja els fitxers index.html i MMA_2025.jpg.
  • Ves a Settings -> Pages.
  • Sota "Source" tria Deploy from a branch, selecciona la branca main i desa els canvis.
